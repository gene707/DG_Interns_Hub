# Linux File System Hierarchy & Permissions

## Key Directories
| Path | Purpose |
|------|---------|
| `/etc` | System configuration files (read‑only for normal users) |
| `/var/log` | Log files generated by services and applications |
| `/home` | User home directories, personal files |
| `/tmp` | Temporary files, cleared on reboot |

## File Permissions
- **chmod** – change mode (rwx bits). Example: `chmod 750 /var/log/secure`
- **chown** – change owner/group. Example: `chown root:syslog /var/log/syslog`
- **SUID** – executable runs with file owner’s privileges. Example: `/usr/bin/passwd` has `rwsr-xr-x` so ordinary users can change passwords.

### Permission Example
```
# Create a script that only root can execute with elevated privileges
sudo touch /usr/local/bin/backup.sh
sudo chmod 4755 /usr/local/bin/backup.sh   # setuid bit (4) + rwx for owner
```
